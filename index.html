mariamalzaabi.ae

My own bilingual portfolio site.

HTML/CSS/JSWebGLArabic RTLGitHub Actions
Visit the site ↗
The need
A personal site that works fully in English and Arabic, loads fast, and shows real engineering instead of a list of skills.
What it does
A static site with a right-to-left Arabic version generated from the same source, a WebGL globe you descend through as you scroll, a live sky of real navigation satellites that GitHub Actions refresh every day, a photo dehazing tool that runs in the browser, and an optional light mode.
Result
No framework and no server costs, hosted on GitHub Pages with a custom .ae domain and email. Accessibility checks pass with zero issues in both languages and on phones.
